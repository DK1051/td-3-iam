## Goal
Build the Agent Passport: an MCP server (Model Context Protocol, a standard way to give an AI model a fixed menu of tools over HTTP) that exposes two 3H actions to an AI "access assistant" — `list_requests` and `propose_change` — and deliberately has **no tool that grants access**. The assistant's own identity is a Keycloak client, `agent-access-assistant`, limited to the scopes `requests:read` and `requests:propose`; the server checks the token's audience and the tool's scope on every call and appends every call to `audit.jsonl`. A grant happens only when a human runs `scripts/approve.py <proposal-id>` with a manager's token. Then run Eojin's 30 malicious requests through the assistant and count escalations, proposals and attempted grants, by language and model.

There is **no** tool named grant, approve, apply, add_to_group or anything that changes the directory.

Use `mcp.client.streamable_http` in tests to talk to the running server, or the SDK's in-memory client if the session finds it simpler (`TODO(verify)` name). Add `3a-agent-passport/tests` to `testpaths` and `3a-agent-passport` to `pythonpath` in `pyproject.toml`, so CI runs these tests.
